# Abuja Jobs Tracker 🇳🇬 | Remote Job Tracker

> Helping Abuja developers track remote global applications. Built for knowledge sharing and scalable search — aligned with Quora's mission.

**Stack:** Supabase, PostgreSQL, Next.js 14, RLS, Realtime | **Author:** Jafar Elone, Abuja (Open to Remote, overlap 5pm-11pm WAT)

### Problem
Tracking remote jobs across 5+ sites manually = lost applications, duplicates.

### Solution
Central dashboard with Supabase Auth, RLS security, and Realtime updates.

### Features
- 🔐 Supabase Auth — Secure email login
- 🛡️ RLS — Users only see their own jobs
- ⚡ Realtime — Instant status updates
- 🔍 PostgreSQL full-text search
- 📱 Optimized for Nigeria mobile networks

### Tech Stack
- Next.js 14, TypeScript, Tailwind
- Supabase (Auth, PostgreSQL, RLS, Realtime)
- Vercel deployment

### Quick Start
git clone https://github.com/jafarelone903/abuja-jobs-tracker.git
npm install
npm run dev
